## Roadmap

The project will be developed in the following stages:

1. **Project planning:** Define the problem statement, scope, requirements, and user stories.
2. **User authentication:** Develop email and password registration and login with appropriate access controls.
3. **Sleep screening:** Implement the PSQI and ISI questionnaires, calculate their scores, and display the results separately.
4. **Sleep diary:** Develop functions for recording, saving, and viewing daily sleep information.
5. **Sleep education:** Provide prewritten sleep tips from reliable health resources.
6. **Testing and evaluation:** Test application functionality and evaluate usability.
7. **Documentation:** Update project documentation based on development and testing progress.
